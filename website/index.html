El problema

Cuando un agente falla, te quedas a ciegas.

Cuando un agente tarda demasiado, gasta más tokens de lo esperado o simplemente se rompe, no hay forma nativa de ver qué ocurrió paso a paso. Las herramientas de observabilidad clásicas te piden una cuenta en la nube, claves de API y enviar datos de producción a servidores ajenos.

Observabilidad en la nube

  • Cuenta, facturación y claves de API
  • Tus prompts y datos salen a servidores externos
  • Coste por evento o por GB ingerido
  • Latencia de red y límites de retención
Lookspan

Observabilidad local-first

  • Todo corre en tu máquina, los datos nunca salen de ella
  • SQLite en ~/.lookspan/lookspan.db — tú eres el dueño
  • Coste de infraestructura cero
  • Un comando: npx lookspan y a observar
Características

Todo lo que necesitas para depurar agentes, en local.

Ingesta, trazas, grafo de spans, costes y alertas. Sin montar infraestructura y sin renunciar a la privacidad de tus datos.

Nativo para MCP

El SDK @lookspan/mcp envuelve cualquier McpClient y emite un span por cada llamada a herramienta, sin tocar el código de tu agente.

Streaming en tiempo real

El endpoint SSE /api/stream empuja cada span.ingested al dashboard al instante. Ves las trazas mientras tu agente las ejecuta, sin polling.

Grafo de spans interactivo

Vista de detalle de cada traza con un grafo navegable (React Flow): jerarquía, duraciones, estados y atributos de cada paso del agente.

Seguimiento de costes

Agrega tokens de entrada, salida, caché y razonamiento; calcula el cost_usd por span y por traza, con desglose por modelo y por proveedor.

SQLite local

Esquema con migraciones versionadas y base de datos en ~/.lookspan/lookspan.db. Configurable por flag o variable de entorno. Tus datos, tu disco.

CLI en una línea

npx lookspan arranca servidor y dashboard sin instalación global. Puertos, host y ruta de la BD configurables por flag o entorno.

Alertas configurables

Avísate cuando una traza falla, supera un coste, gasta demasiados tokens o tarda de más. Toast en el dashboard, notificación de escritorio y consola.

Privado por defecto

Escucha en 127.0.0.1 y redacta credenciales (api_key, token, password…) antes de persistir. Token opcional si lo expones.

OpenTelemetry (OTLP)

Receptor OTLP/HTTP en /v1/traces. Apunta cualquier app instrumentada con OTel a Lookspan: los atributos gen_ai.* se mapean a modelo, proveedor y tokens.

Cómo funciona

De tu agente al dashboard en tres pasos.

Instrumenta una vez con un adaptador, arranca el CLI y observa. Los spans viajan por HTTP, se validan y normalizan, y aparecen en tiempo real.

🤖 Agente MCP · LangGraph · CrewAI · HTTP
POST /api/ingest
⚙️ Collector valida · normaliza · redacta
🗄️ SQLite ~/.lookspan/lookspan.db
SSE /api/stream
📊 Dashboard trazas · grafo · costes
  1. 1

    Instrumenta

    Envuelve tu cliente MCP o añade el callback de LangGraph/CrewAI. Una línea, sin reescribir tu agente.

  2. 2

    Arranca

    Ejecuta npx lookspan. El servidor escucha en :3100 y sirve el dashboard.

  3. 3

    Observa

    Cada span aparece en vivo: jerarquía, duraciones, estados, tokens y coste en USD.

Integraciones

Instrumentar tu agente es una línea de código.

Elige tu framework. Compatible con cualquier agente capaz de hacer una petición HTTP. 

// Instrumenta cualquier cliente MCP — cada callTool emite un span
import { wrapMcpClient, HttpSpanExporter } from '@lookspan/mcp';

const exporter = new HttpSpanExporter({
  endpoint: 'http://127.0.0.1:3100/api/ingest',
});

const { client } = wrapMcpClient(mcpClient, {
  exporter,
  agentId: 'mi-agente',
});

// Úsalo exactamente igual que antes
await client.callTool({ name: 'read_file', arguments: { path: '/tmp/foo.txt' } });
from lookspan import LookspanClient
from lookspan_langgraph import LookspanCallbackHandler

client = LookspanClient(endpoint="http://127.0.0.1:3100/api/ingest")
handler = LookspanCallbackHandler(client=client, agent_id="mi-agente")

# Pasa el handler como callback — LangGraph hace el resto
result = graph.invoke({"messages": []}, config={"callbacks": [handler]})
client.flush()
from crewai import Crew
from lookspan import LookspanClient
from lookspan_crewai import attach_lookspan

client = LookspanClient(endpoint="http://127.0.0.1:3100/api/ingest")
attach_lookspan(client, agent_id="research-crew")

# Una llamada y toda la crew queda instrumentada
crew = Crew(agents=[...], tasks=[...])
crew.kickoff()
client.flush()
# Cualquier lenguaje que pueda hacer un POST
curl -X POST http://127.0.0.1:3100/api/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "source": "mi-agente",
    "spans": [{
      "traceId": "tr_abc123",
      "spanId": "sp_def456",
      "type": "llm_call",
      "name": "completion",
      "status": "ok",
      "framework": "custom",
      "model": "gpt-4o",
      "provider": "openai"
    }]
  }'
# Reutiliza tu instrumentación OpenTelemetry existente
export OTEL_EXPORTER_OTLP_TRACES_ENDPOINT=http://127.0.0.1:3100/v1/traces
export OTEL_EXPORTER_OTLP_PROTOCOL=http/json

# Los atributos gen_ai.* se mapean a modelo, proveedor y tokens,
# y el coste se calcula con la tabla de precios.
